# Pixel Runner

HTML / CSS / JavaScriptだけで作った、横スクロールアクションゲームのMVPです。

## 遊び方

`index.html` をブラウザで開くか、VS CodeのLive Serverなどで配信して起動します。

- `←` / `→` または `A` / `D`: 移動
- `SPACE` または `W`: 2段ジャンプ。空中で長押しすると向いている方向へ平行移動
- `X`: 攻撃
- `Z`: 前方へビームを発射
- スマートフォンでは画面下のボタンを使用

敵を倒しながらコインを集め、ステージ右端の旗に到達するとクリアです。全8枚のコインを集めるとボーナスが加算されます。

## ファイル構成

- `index.html`: ゲーム画面の構造、HUD、操作ボタン
- `style.css`: レイアウト、配色、レスポンシブ対応
- `script.js`: プレイヤー操作、物理演算、敵、コイン、描画、ゲーム進行
